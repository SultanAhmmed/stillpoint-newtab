Stillpoint New Tab
==================

A calm Chromium new-tab extension with selectable search engines and backgrounds.

Install in Chrome, Brave, Edge, or another Chromium browser:

1. Open the browser extensions page:
	- Chrome: chrome://extensions
	- Brave: brave://extensions
	- Edge: edge://extensions
2. Turn on Developer mode.
3. Choose Load unpacked.
4. Select this duck-home folder.
5. Open a new tab. Stillpoint will replace the default new-tab page.

Features:
- Search with DuckDuckGo, Brave Search, Google, Bing, Startpage, or Ecosia.
- Choose from every bundled background in assets/.
- Upload multiple personal images; they appear below the upload control and can be removed individually.
- Reset to defaults removes all uploaded images and restores the original settings.
- Settings persist on this device.
- Press / to focus search and Escape to clear it or close settings.
- No external extension service or account is required.

To update the extension after editing files, return to the extensions page and click Reload.
